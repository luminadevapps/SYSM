## Overview

**SYSM** is a comprehensive macOS application for system maintenance, drive management, and troubleshooting, with specialized support for Hackintosh systems. It brings nine core modules together in one native app so you can keep a Mac (or OpenCore build) healthy without juggling a dozen command-line tools. Free and open-source.

## ✨ Features

- **Drive management** — mount, unmount, and inspect EFI partitions
- **System information** — hardware, macOS, and boot diagnostics at a glance
- **Kext management** — install and manage kernel extensions, including AppleHDA
- **Audio tools** — layout-id helpers and audio troubleshooting
- **Encoding utilities** — quick conversions for common maintenance tasks
- **SSDT generation** — build OpenCore-ready ACPI tables from templates
- **OpenCore config editor** — edit `config.plist` without leaving the app
- **System monitoring** — CPU, memory, and SIP status checks
- **Automated troubleshooting** — one-click diagnostics for common issues

### Hackintosh / OpenCore extras

OpenCore detection and optimization, security monitoring via SIP status, network diagnostics, CPU monitoring, and boot-management utilities.

## 🚀 Installation

1. Download the latest `SYSM.dmg` from [Releases](../../releases).
2. Open the DMG and drag **SYSM** into your **Applications** folder.
3. Launch it — approve elevated access when prompted for privileged features.
